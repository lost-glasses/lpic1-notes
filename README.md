# LPIC-1 Notes

My personal notes and exercises.

## About This Repository

This repository is my personal knowledge base and notebook while studying for the LPIC-1 certification. It contains theoretical notes, command references, practical exercises, and documentation of real scenarios I encountered in my lab.

## Structure

- `01-basics/` — Linux fundamentals, file management, links, redirection
- `02-text/` — grep, sed, awk, cut, sort, wc
- `03-disks/` — fdisk, parted, LVM, fsck, mount, swap
- `04-network/` — IP, DNS, routing, SSH, NTP
- `05-systemd/` — systemctl, journalctl, services, runlevels
- `06-time/` — chrony, hwclock, rsyslog, locale
- `07-mail/` — postfix, mail, queue management
- `08-advanced-linux/` — Bash scripting, GPG, sudoers, cron, VNC, X11

## Format

Each section contains two files:
- `README.md` — theoretical notes and command references
- `EXERCISES.md` — practical exercises with solutions and expected output
